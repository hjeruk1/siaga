Design implication

1

Butuh objek baru: Modul Ajar

Dimiliki akademik, periodenya mingguan, menjadi sumber referensi guru.

2

Butuh objek baru: Focus Theme

Dibuat guru per tanggal/rombel, ditautkan ke modul ajar, lalu menjadi konteks daily record.

3

Daily record mengambil prefill dari focus theme

Guru tidak perlu mengetik tema inti berulang untuk setiap anak.

4

Yang individual tetap catatan anak

Focus theme menjelaskan pembelajaran hari ini; catatan anak menjelaskan bagaimana anak merespons.

Recommended placement

  • Modul ajar: dibuat/diunggah akademik per minggu.
  • Focus theme: guru set sekali per kelas per hari sebelum mengisi anak.
  • Daily record: focus theme muncul sebagai konteks read-only/editable link, lalu guru isi domain + note per anak.

Question to decide

  • Apakah focus theme wajib dibuat sebelum daily record bisa diisi?
  • Atau daily record tetap bisa diisi, tapi status hari itu “belum ada focus theme”?
