# SIAGA Documentation Archive

Folder ini menyimpan dokumen lama yang sudah diserap ke `docs/siaga-documentation.md` atau artifact generasi lama yang tidak lagi menjadi bacaan utama.

- Untuk orientasi terbaru, baca `docs/siaga-documentation.md` terlebih dahulu.
- Spec dan plan di `docs/superpowers/` tetap dipisah sebagai decision/execution trail.
